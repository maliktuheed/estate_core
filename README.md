# EstateCore

A simple and responsive real estate website built with React and Vite.

## Features

* Responsive design
* About Us section
* Projects section
* Project slider
* Testimonials
* Contact form
* Web3Forms integration
* Smooth animations

## Technologies

* React.js
* Vite
* Tailwind CSS
* Framer Motion
* React Toastify
* Lucide React
* Web3Forms

## Installation

Clone the project:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd estatecore
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
VITE_WEB3FORMS_ACCESS_KEY=your_access_key
```

Run the project:

```bash
npm run dev
```

## Build

```bash
npm run build
```
